🌍 ESP32 Environmental Monitor

An ESP32‑based environmental monitoring system using BME280, BMP280, and MQ‑135 sensors to measure temperature, humidity, pressure, and air quality.
The firmware is written in modular C++ and provides local sensor polling and real‑time serial output.
The project is designed for future expansion with a web interface, SPIFFS CSV logging, and MQTT data streaming.

---

⚙️ Features

ESP32 microcontroller

BME280 sensor (temperature, humidity, pressure)

BMP280 sensor (temperature, pressure)

MQ‑135 gas sensor (air quality)

Modular C++ firmware (src/ + include/)

Real‑time serial output

Clean PlatformIO project structure

Ready for future extensions (web UI, SPIFFS logging, MQTT)
